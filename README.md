## 📌 Project Overview
This project analyzes 500 supermarket transactions to uncover insights regarding product sales, top-performing branches, dominant categories, payment methods, and customer ratings.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Tool:** Jupyter Notebook / VS Code

## 📊 Live Analysis Summary
- **Highest Selling Product:** Cheese (Generated highest total sales)
- **Best Performing Branch:** Branch C (Mumbai - Total Sales: ₹72,469.45)
- **Top Category:** Beverages (Total Sales: ₹56,108.24)
- **Most Popular Payment Method:** UPI (127 transactions)
- **Customer Spend Insight:** Normal customers spent slightly more on average (₹497.07) than Members (₹483.14).
- **Average Customer Rating:** 3.99 / 5
